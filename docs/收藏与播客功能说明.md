# 收藏、播客与网页收藏

当前选择：**辅助功能和屏幕录制已授权给“XiaoGPT 控制中心”**。指定播客单集、最新一期、播客倍速和加入指定歌单已启用；测试歌单为“陶吉吉”，实际写入尚待最终验收。屏幕录制只用于在本机识别网易云窗口中的歌单名称，不保存或上传截图。音乐喜欢收藏、播客快进后退、文字稿/简介摘要和网页收藏保留；网页收藏首次使用仍可能需要相应浏览器自动化授权。

先唤醒“小爱同学”，再说“电脑……”或“Mac……”。新功能沿用现有固定指令解析，不让模型生成系统操作代码。

## 音乐收藏与歌单

要求网易云已登录、当前歌曲已选好，且系统能读取到网易云歌名。收藏前会核对两次歌名和歌手，期间退出自动接曲，避免自动切歌误加。收藏操作不恢复连续队列；如需要请重新说连续播放。

“我喜欢”通过网易云原生控制菜单读取和操作，已经喜欢时不再点击。指定歌单通过本机识别客户端的“收藏到歌单”窗口，精确匹配现有歌单名称。没有歌单或存在多个匹配时会提示；不自动创建、删除或重命名歌单。未识别到客户端成功提示时只报告已发送，不冒称成功。`music_library.json` 中的别名会先应用，例如说“陶喆”会映射到歌单“陶吉吉”。

语音“加入通勤歌单”匹配名为“通勤”或“通勤歌单”的现有歌单；两者都存在时请使用更明确的名称。窗口布局或客户端版本变化可能导致识别失败，此时会停止，需在应用中确认。

## 播客倍速与跳转

倍速支持0.5至3.0之间的一位小数，设置后读取客户端速度进行核对。它修改小宇宙当前设置，不自动购买会员或开启其他音频增强功能。已实测 1.0→1.5→1.0 倍速切换；窗口重绘时可能出现一次“前台应用已变化”，程序会自动重试一次。

当小宇宙是系统当前媒体应用时，快进/后退通过已验证的进度跳转执行；否则只操作小宇宙播放器的原生按钮，快进支持30秒的倍数、后退支持15秒的倍数，每次最多10分钟。不会将指令发送给浏览器音视频。超出音频范围时以应用实际边界为准。

## 播客摘要与文字稿

先读取小宇宙当前单集标题，再匹配公开节目页。真实文字稿正文才可作为完整内容摘要来源；`mediaId`、音频地址或“有文字稿”的标记不是正文。有时间标签时保留重要位置，没有时间标签就不编造。

若公开页面只有简介，会明确说明没有完整文字稿。此时可以说“电脑总结节目简介”，得到明确标注为简介范围的摘要。不会将简介摘要说成完整节目的重点。

本机文字稿可放入现有Obsidian库的 `小爱语音/播客文字稿/`，使用单集标题或已验证单集编号命名，支持 `.md`、`.txt`、`.srt`。读取范围限定在这个目录，忽略符号链接，每个文件不超过1MB；总结上限为12万字，长稿分段概括后合并。

找到本机文字稿后，音箱会复述节目名，并说明将发送至MiniMax。必须说“确认发送本期文字稿给MiniMax总结”才发送；确认有效期3分钟，文件变化后需重新确认。取消或超时不发送。公开文字稿/简介的摘要使用现有MiniMax API，会产生相应调用用量。

## 网页保存与隐私

读取Safari/Chrome当前标签页的标题和地址，不读取网页正文，不上传网页内容。浏览器不明确时会请你说出Chrome或Safari。保存位置为当前Obsidian库 `小爱语音/网页收藏.md`，包含保存时间、标题、链接及口述备注；同一链接不重复写入。

拒绝本地文件地址、脚本地址、带账号密码或明显登录令牌参数的链接。网页登录页请先切换到普通文章再收藏。

## 权限与原有功能

统一由 **XiaoGPT 控制中心** 执行。辅助功能用于网易云原生菜单、小宇宙播放器和指定单集；屏幕录制用于在本机识别网易云窗口中的歌单名称（倍速优先走辅助功能，失败时才用屏幕识别）。程序只选择网易云或小宇宙窗口，不保存、上传截图，不扫描其他应用。

读取网页标题和链接需要该程序的Safari/Chrome自动化权限，系统可能在首次使用相应浏览器时询问。无需开启浏览器“允许来自Apple事件的JavaScript”。

指定播客自动选集已改由控制中心执行并启用；晨报提醒汇总仍关闭。加歌单需要控制中心的屏幕录制权限，撤销该权限后功能会明确提示并停止，不会误点其他窗口。
