# XiaoGPT · LX06 · MiniMax M3

本目录是实际部署位置，使用独立 Python 虚拟环境。已识别 LX06，DID 由 discover 自动识别。无需刷机，保留原厂小爱功能。

## 语音使用

先说“小爱同学”，听到提示音后再连贯说出前缀和问题：

- “请问上海明天会下雨吗？”
- “请问今天有哪些科技新闻？”
- “问AI，搜索最近的人工智能新闻。”
- “请问今天几号？”

主要前缀为“问AI”和“请问”。已兼容实际出现的 AI、揾没、揾AI、请揾、问人工智能、揾人工智能等识别结果。

普通播放音乐、智能家居等请求不要加此前缀，由原厂小爱处理。已另行接入Mac本机网易云播放控制，见下方“Mac语音控制”；现支持通过Mac网易云语音指定歌曲搜索播放，见“Mac语音指令.md”。AI 请求会先播报“正在问MiniMax”。

## 联网查询

模型为 MiniMax-M3，关闭深度思考。realtime_bot.py 对知识和事实问题通过 MiniMax 官方 Responses API 提供 web_search 工具；明显涉及天气、新闻、最新消息、价格等问题要求实际搜索，并检查是否返回成功搜索记录和来源链接，失败时明确表示无法确认，避免退回模型猜测。

联网结果在完整返回且检查搜索记录后播报。检索内容的时效性和正确性仍取决于来源；程序无法独立证明每项事实。日期与时间直接读取 Mac 的北京时间（Asia/Shanghai），请保持系统时间正确。天气问题请明确城市。

简单问候、算术及故事笑话沿用原来的流式问答。联网查询通常增加等待时间。查询使用现有 MiniMax API Key，API 用量按 MiniMax 账户规则结算。

来源记录在 state/search/latest.json，包括查询时间、问题、实际搜索词、来源链接、摘要和回答。保留最近30轮记录；记录包含你的提问，请勿直接公开。没有来源、搜索失败或超时将返回查询失败提示。该检查确认工具执行和来源存在，不等于逐条事实核查。

官方工具说明：https://platform.minimax.cn/docs/guides/server-tools

## 自启动和运行

local.xiaogpt.lx06 用户 LaunchAgent 已加载。重启 Mac 并登录当前用户后自动运行；异常退出至少间隔30秒重启。Mac 休眠、关机、断网或退出登录时无法提供服务。

停止：

```sh
launchctl bootout gui/$(id -u)/local.xiaogpt.lx06
```

重新加载：

```sh
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.xiaogpt.lx06.plist
```

重启运行中的服务：

```sh
launchctl kickstart -k gui/$(id -u)/local.xiaogpt.lx06
```

运行日志为 state/service.log、state/error.log，可能包含问题与回答。

manage.py 支持 discover（登录和设备识别）、api（基础模型测试）、tts（播报测试）、install（安装并加载自启动）、run（前台运行），使用本目录 .venv/bin/python 执行。api 子命令只测试基础模型，不测试搜索模块。

## 强制联网触发词

直接唤醒后说“联网搜索上海明天天气”即可强制联网，也支持“强制联网搜索”“联网查询”“上网搜索”。仍可说“请问，联网搜索今天的科技新闻”。等待提示为“正在联网搜索”。

程序保留搜索命令传给模型，并要求取得成功搜索调用和来源链接；没有搜索记录、查询失败或没有来源时，拒绝播报具体事实，返回失败提示。查询时间、实际搜索词、来源链接保存在 state/search/latest.json，forced_search 字段标记是否为显式联网请求。实测完成一次强制搜索并取得10个来源。

抢答抑制验证：4项自动检查通过，原有联网模块7项检查通过，LX06停止接口实测成功，两次操作合计约0.68秒。优化效果需在实际语音环境下观察，日志会记录AI识别记录的同步耗时及停止接口结果。修改前运行层备份为 state/runtime.before-interruption.py。

## Mac语音控制 · 网易云音乐

先唤醒“小爱同学”，等提示音后说：

- “让电脑打开网易云音乐并播放”（打开或恢复当前播放列表）
- “让Mac打开网易云音乐”（只打开）
- “让电脑暂停网易云音乐”
- “让Mac网易云下一首” / “让Mac网易云上一首”

也支持“请问，让Mac打开网易云音乐并播放”。必须明确提到Mac或电脑以及网易云/音乐操作；不带Mac目标的普通音乐指令仍由原厂小爱处理。建议使用“电脑”避免英文Mac被误识别。

这些命令直接由本机 mac_control.py 解析、执行，不交给模型生成系统命令。提示音为“正在操作Mac”。支持打开、播放、暂停、上一首、下一首及按歌手/歌名点播；不执行任意系统命令。例：让电脑用网易云播放陶喆的普通朋友。

XiaoGPT Mac控制.app 是专用辅助程序，通过macOS辅助功能操作网易云原生“控制”菜单。权限已由用户开启，打开和暂停/恢复已实机验证。播放/暂停会检查菜单状态后执行，重复说“播放”不会切成暂停。若没有歌曲，需先在网易云选择可播放歌曲。账户、版权及会员限制仍由网易云处理。

音乐由Mac当前选择的音频输出设备播放，不会自动转到LX06。Mac须登录当前用户、GUI会话可用；锁屏或系统权限变化可能影响控制。程序更新签名后若权限失效，需要重新检查“系统设置 → 隐私与安全性 → 辅助功能”。

辅助程序源码为 MacMusicControl.swift，执行记录在 state/mac-control/ 中（最多保留30条），不包含账号密码。可以在辅助功能设置中关闭该程序的权限来撤销控制。
