# 控制中心与个人媒体库

更新：2026-10-16。统一辅助程序已授权，音乐与播客播放控制已切换；日历、提醒、备忘录、演示仍保留原授权路径。原辅助程序暂不删除。

## 统一授权的边界

“XiaoGPT 控制中心.app”将原有音乐、Mac扩展、演示翻页、媒体扩展、收藏播客、可选提醒读取集中在一个应用身份内执行，不是启动旧应用转发，因此辅助功能只需管理这个新应用条目。

macOS 仍分别管理辅助功能、自动化（还可能按被控应用细分）、日历、提醒事项与屏幕录制。不能通过一个系统开关自动授予全部权限，也不会自动继承旧应用的授权。当前只请求辅助功能，屏幕录制保持不开放。日历/提醒和浏览器自动化在统一应用下尚需分别验证，不能因为已开启辅助功能就宣称它们已可用。

迁移开关在 `mac_features.json` 的 `control_center_enabled`；默认未启用。旧辅助程序和授权在迁移验收前不删除。关闭迁移开关可回到原有控制路径；新媒体库指令不伪装为旧路径已支持。

| 电脑网易云播放歌单陶吉吉 | 在此账号公开可见歌单中按名称精确匹配，并请求桌面端播放 |

当前公开资料匹配到44个可见歌单，其中6个由其他账号创建，作为收藏歌单范围。数量会随账号操作变化。通过公开元数据读取，不提取客户端登录令牌；私密或无法公开读取的歌单不保证支持。`music_library.json` 保存账号公开标识与歌单别名，不含密码。重名歌单拒绝盲选。API返回曲目可能只是部分预览，因此不把它当完整歌单导出；实际队列由已登录网易云桌面端处理。

“播放歌单”和“把当前歌曲加入歌单”是不同功能；后者仍按未开放屏幕录制的偏好关闭。原指定公开播客搜索播放、倍速功能也不自动重新开启。

## 核验规则

- 小宇宙仅以当前播放栏或全屏播放/暂停按钮确认状态，不从推荐条目的状态推断播放成功，也不单凭可能缓存的系统媒体信息宣布成功。
- 随机/订阅播放需要所选单集名称出现在实际播放器，且播放器状态为播放中。
- 网易云歌单请求后检查实际媒体应用、播放状态、首曲名称和歌手。无法核实则明确“已发送但未确认”，不说已完成。
- 公开元数据接口不构成服务稳定承诺，接口变化时返回失败说明；播放仍受版权、会员和地区限制。

## 2026-10-16 授权与实机核对补充

统一程序曾检测到辅助功能授权有效；订阅更新随机播放与暂停均已核对真实播放器状态。按订阅节目名称选集时发现 iOS-on-Mac 按钮可能返回 AXPress 成功但不切页，已改为基于辅助功能控件边界点击及等待页面标识。没有使用屏幕录制。

修复后的签名发生变化，系统日志明确显示 Accessibility 的旧/新 cdhash 不匹配；移除重加后仍引用旧签名。随后用 `tccutil reset Accessibility local.xiaogpt.control-center` 只清除了此应用的旧授权，并由当前版本重新请求。需要用户重新开启当前条目后继续核对；没有修改权限数据库或绕过系统授权。

为避免迁移导致原有日历、提醒、备忘录和演示失效，激活脚本会保留这些动作的旧程序路径，直到各自系统权限单独迁移完成。因此“统一辅助程序已构建”不等于所有权限和所有功能已经完成迁移。

## 最终启用状态

重置旧签名授权后，当前版本检测辅助功能=true、屏幕录制=false；未再重编译原生程序。`control_center_enabled=true` 已写入配置并重启常驻服务。小宇宙订阅更新随机播放、指定已订阅节目选集、播放与暂停经过真实播放器状态检查；网易云暂停经统一程序实测。用户已确认真实语音“电脑播放小宇宙我的订阅”和“电脑暂停小宇宙”均成功。

按节目选集会先准备订阅列表，页面未切换时只在尚未播放前进行有界重试；无法核实则不报成功。“最新一期”排序尚不能可靠保证，现已明确拒绝该变体，推荐使用“某节目的一集”，避免误把旧集当最新。

`control_center_legacy_actions` 保留 `calendar_`、`reminder_`、`reminders_`、`notes_`、`keynote_`，未把仅有辅助功能权限的统一程序当作已获日历/自动化权限。原屏幕录制相关歌单写入/倍速、公开播客单集自动选择、晨报提醒和蓝牙等偏好不变。
